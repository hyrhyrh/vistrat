# 安全策略 / Security Policy

## 支持版本 / Supported Versions

我们仅对最新的 `main` 分支和最近一个 release 提供安全更新。

We provide security updates for the latest `main` branch and the most recent release only.

## 报告漏洞 / Reporting a Vulnerability

如果你发现了安全漏洞，**请勿**在 GitHub Issue 中公开讨论。

If you discover a security vulnerability, **please do not** open a public GitHub issue.

请通过以下方式私下报告：

Please report it privately via:

- 邮箱 / Email: `security@vistrat.example.com`（维护者请替换为真实邮箱 / maintainers: replace with a real address）
- 或使用 GitHub 的 [Private Security Advisory](https://docs.github.com/en/code-security/security-advisories) 功能

报告时请包含：

When reporting, please include:

1. 漏洞描述与影响 / Description and impact
2. 复现步骤 / Reproduction steps
3. 受影响的版本 / Affected versions
4. 可能的修复建议（可选）/ Suggested fix (optional)

## 响应时限 / Response Time

我们承诺尽力在 **7 个工作日**内确认收到报告，并在合理时间内提供修复或缓解方案。

We commit to acknowledging your report within **7 business days** on a best-effort basis, and providing a fix or mitigation within a reasonable timeframe.

## 致谢 / Acknowledgements

感谢负责任地披露漏洞的安全研究者。经报告者同意后，我们会在 release notes 中致谢。

Thanks to security researchers who disclose responsibly. With your consent, we will credit you in release notes.
