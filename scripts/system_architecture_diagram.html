🛠️ 详细技术栈

🌐 前端技术

• React 18 (并发特性)
• TypeScript 5.0+ (类型安全)
• Ant Design 5.0+ (企业UI)
• Vite 4.0+ (极速构建)
• React Router 6 (路由管理)
• Axios + WebSocket (网络通信)

⚙️ 后端技术

• FastAPI 0.115+ (异步框架)
• Python 3.9+ (编程语言)
• Uvicorn (ASGI服务器)
• OpenCV 4.8+ (视频处理)
• Pydantic 2.5+ (数据验证)
• JWT + bcrypt (安全认证)

🤖 AI模型

• 通义千问VL-Max (视觉理解)
• Moonshot-v1 (文本分析)
• 向量数据库 (RAG检索)
• 智能模型选择 (性能优化)
• 多模态分析 (图文理解)
• 自定义提示词 (场景适配)

💾 数据存储

• PostgreSQL 16 (主数据库)
• Elasticsearch 8.11 (搜索引擎)
• Redis 7 (缓存数据库)
• MinIO (对象存储)
• 本地文件系统 (临时存储)
• 数据备份与恢复 (高可用)

🔗 通信协议

• HTTP/HTTPS (RESTful API)
• WebSocket (实时通信)
• MJPEG (流媒体协议)
• RTSP (视频流协议)
• TCP/UDP (网络传输)
• JSON (数据格式)

🐳 部署运维

• Docker (容器化)
• Docker Compose (服务编排)
• Nginx (反向代理)
• Linux (运行环境)
• 健康检查 (服务监控)
• 日志管理 (故障排查)
