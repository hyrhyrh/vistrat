# 企业微信告警统计报表功能说明

## 功能概述

已成功实现将告警统计数据发送到企业微信群的功能。系统可以自动生成格式化的Markdown报表,并通过企业微信群聊机器人推送给相关人员。

## 实现的功能

### 1. 后端服务扩展

#### 新增服务方法
- **文件**: `backend/services/alert_notification_service.py`
- **方法**: `send_daily_report(report_content: str, title: str)`
- **功能**: 将自定义报表内容发送到企业微信群

```python
async def send_daily_report(self, report_content: str, title: str = "每日告警统计报表"):
```

### 2. API端点

- **文件**: `backend/api/alert_notifications.py`

**响应示例**:
```json
{
  "success": true,
  "message": "告警统计报表已发送"
}
```

## 报表内容格式

### 当前实现的报表

报表包含以下内容:
1. **告警总览**: 告警总数、告警级别、平均置信度
2. **告警类型分布**: 不同告警类型的统计
3. **时间分布**: 告警发生的时间段分布
4. **监控点位分布**: 不同监控点的告警数量
5. **关键发现**: 分析总结
6. **建议**: 改进措施

### 报表示例

```markdown
## 📊 今天的告警数据统计

根据查询结果,**今天(2025年10月14日)共有14条告警数据**。以下是详细分析:

### 告警总览
- **告警总数**: 14条
- **告警级别**: 全部为 critical(严重)级别
- **置信度**: 平均置信度 0.98

### 告警类型分布
所有14条告警都与**安全帽检测**相关:
- **未佩戴安全帽**: 8条告警
- **佩戴安全帽**(检测违规): 6条告警

### 时间分布
告警主要集中在两个时段:
- **06:00-07:00**: 8条告警(早班作业时段)
- **11:00-12:00**: 6条告警(上午作业时段)

### 监控点位分布
1. **示例摄像头01**: 6条告警(11:15-11:16)
2. **示例项目-示例点位**: 2条告警(06:41)
3. **施工区域**: 6条告警(06:39-06:42)

### 关键发现
- 所有告警都是关于安全帽佩戴问题,说明这是今天的主要安全隐患
- 告警集中在早班开始(6点)和上午工作时段(11点),可能是工人在这些时段安全意识较薄弱
- 示例摄像头01在短时间内(11:15-11:16)产生了6条告警,可能存在持续的违规行为

### 建议
1. 加强早班和上午时段的安全巡查
2. 对示例摄像头01、示例项目-示例点位等高发区域进行重点监管
3. 开展安全帽佩戴的专项培训和宣传
```

## 技术架构

### 数据流程

```
1. 查询Elasticsearch获取告警数据
   ↓
2. 生成Markdown格式的报表内容
   ↓
3. 调用API端点 /api/alert-notifications/send-daily-report
   ↓
4. alert_notification_service 处理报表
   ↓
5. WeChatWorkAdapter 格式化Markdown消息
   ↓
6. 发送HTTP POST请求到企业微信Webhook
   ↓
7. 企业微信群聊机器人推送消息
```

### 企业微信Markdown支持

系统使用企业微信的Markdown格式,支持:
- **标题**: `# ## ###`
- **加粗**: `**文本**`
- **斜体**: `*文本*`
- **列表**: `- 项目`
- **代码**: `` `代码` ``
- **链接**: `[文字](URL)`
- **引用**: `> 引用`

## 配置说明

### 企业微信Webhook配置

系统从数据库 `system_configs` 表中读取企业微信Webhook配置:

```sql
SELECT * FROM system_configs WHERE param_code = 'qywx_webhook';
```

配置项:
- `param_code`: `qywx_webhook`
- `param_val`: 企业微信群聊机器人Webhook URL
- `param_name`: 企业微信Webhook地址
- `param_desc`: 用于发送告警通知的企业微信群聊机器人Webhook地址

### 服务配置

在 `services/alert_notification_service.py` 中配置:
- 定时通知时间: 11:00, 17:00
- 即时通知: 启用(critical和error级别)
- 通知缓冲区: 最多1000条告警

## 使用场景

### 1. 定期报表推送

设置定时任务(如cron),每天固定时间发送告警统计报表:

```bash
# 每天早上9:00发送
0 9 * * * cd /path/to/backend && python scripts/send_daily_alert_report.py
```

### 2. 即时通知

系统自动检测严重告警,立即推送到企业微信群:
- critical级别: 立即推送
- error级别: 立即推送
- warning级别: 汇总推送
- info级别: 汇总推送

### 3. 自定义报表

根据业务需求生成自定义报表并发送:

```python
import httpx
import asyncio

async def send_custom_report():
    api_url = "http://localhost:16532/api/alert-notifications/send-daily-report"

    payload = {
        "title": "📊 周报",
        "report_content": """## 本周工作总结

### 完成事项
- 处理告警 128 条
- 分析视频流 45 个
- 系统稳定性 99.8%
        """
    }

    async with httpx.AsyncClient() as client:
        response = await client.post(api_url, json=payload)
        print(response.json())

asyncio.run(send_custom_report())
```

## 扩展开发

### 添加新的报表类型

1. 在 `scripts/` 目录下创建新的报表生成脚本
2. 查询Elasticsearch或数据库获取数据
3. 格式化为Markdown内容
4. 调用 `/api/alert-notifications/send-daily-report` API发送

### 添加新的通知渠道

1. 在 `services/notification_adapters.py` 中创建新的适配器类
2. 实现 `send()` 方法
3. 在 `alert_notification_service.py` 中注册适配器

### 自定义报表模板

创建报表模板文件,动态填充数据:

```python
from string import Template

template = Template("""## 📊 $title

### 统计数据
- 总数: $total
- 成功: $success
- 失败: $failed

### 详细信息
$details
""")

report = template.substitute(
    title="今日处理统计",
    total=100,
    success=95,
    failed=5,
    details="详细信息..."
)
```

## 故障排查

### 常见问题

1. **通知发送失败**
   - 检查Webhook URL是否正确
   - 检查网络连接
   - 查看后端日志: `tail -f /tmp/backend.log`

2. **格式显示异常**
   - 检查Markdown语法
   - 确保使用企业微信支持的语法
   - 测试简单的Markdown内容

3. **服务未响应**
   - 检查后端服务是否运行: `ps aux | grep "python main.py"`
   - 检查端口是否被占用: `lsof -i :16532`
   - 重启后端服务
