# 告警数据字段存储修复说明

## 问题描述

### 原有问题

在生成 `video_alerts` 视频告警数据时，三个字段存储的内容完全相同：

```json
{
  "alert_content": "检测到1人未佩戴安全帽",
  "description": "检测到1人未佩戴安全帽",
  "ai_response": "检测到1人未佩戴安全帽"
}
```

这导致：
❌ 丢失了详细的违规描述信息
❌ 丢失了完整的AI原始响应
❌ 告警数据价值大打折扣

### 期望的存储格式

根据AI响应的完整结构，三个字段应该分别存储：

```json
{
  "alert_content": "检测到1人未佩戴安全帽",  // 简短结论
  "description": "画面右侧远处有一名人员头部无安全帽，疑似违规",  // 详细描述
  "ai_response": "```json\n{\n  \"violations\": {...}\n}\n```"  // 完整AI响应
}
```

## 修复方案

### 1. 修改告警回调数据结构

**文件：** `backend/services/stream_frame_analyzer.py`

**修改位置：** `_handle_composite_alert_callback` 方法 (第848-877行)

**修改内容：**
- 新增 `alert_details` 字段 - 从violation的details数组提取详细描述
- 新增 `ai_response_full` 字段 - 存储完整的AI原始响应

```python
# 提取详细描述（将details数组合并为字符串）
details_list = violation.get('details', [])
details_text = '；'.join(details_list) if details_list else ''

alert_data = {
    'alert_content': violation.get('conclusion', ''),  # 简短结论
    'alert_details': details_text,  # 详细描述
    'ai_response_full': violation.get('ai_response_full', ''),  # 完整AI响应
    ...
}
```

### 2. 修改告警保存逻辑

**文件：** `backend/services/stream_analysis_service.py`

**修改位置：** `_save_alerts_to_elasticsearch` 方法 (第698-702行)

**修改内容：**
正确映射三个字段，避免重复：

```python
# AI分析结果
'confidence': confidence,
'alert_content': alert.get('alert_content', ''),  # 简短结论
'description': alert.get('alert_details', alert.get('alert_content', '')),  # 详细描述
'ai_response': alert.get('ai_response_full', alert.get('alert_content', '')),  # AI完整响应
```

### 3. 丰富violation数据

**修改内容：**

## 数据流转过程

### 完整的数据流

```
1. AI返回响应
   ↓
   包含: violations.safety_helmet.details = ["画面右侧远处有一名人员头部无安全帽，疑似违规"]
   包含: violations.safety_helmet.conclusion = "检测到1人未佩戴安全帽"
   包含: 完整JSON响应

2. CompositeResponseParser.parse_composite_response()
   ↓
   为每个violation添加 ai_response_full 字段

3. stream_frame_analyzer._handle_composite_alert_callback()
   ↓
   构建alert_data:
   - alert_content: conclusion (简短)
   - alert_details: details数组合并 (详细)
   - ai_response_full: 完整AI响应

4. stream_analysis_service._save_alerts_to_elasticsearch()
   ↓
   保存到ES:
   - alert_content: 简短结论
   - description: 详细描述
   - ai_response: 完整响应
```

## 字段说明

| 字段 | 数据来源 | 用途 | 示例 |
|------|---------|------|------|
| `alert_content` | `violation.conclusion` | 简短的告警内容，用于列表展示 | "检测到1人未佩戴安全帽" |
| `description` | `violation.details` 数组合并 | 详细的违规描述，用于详情展示 | "画面右侧远处有一名人员头部无安全帽，疑似违规" |
| `ai_response` | `violation.ai_response_full` | 完整的AI原始响应，用于审计和调试 | 完整的JSON响应文本 |

## 向后兼容性

### 降级处理

如果某些字段缺失，代码会自动降级：

```python
'description': alert.get('alert_details', alert.get('alert_content', '')),
'ai_response': alert.get('ai_response_full', alert.get('alert_content', '')),
```

- 如果 `alert_details` 不存在，使用 `alert_content`
- 如果 `ai_response_full` 不存在，使用 `alert_content`
- 保证系统不会因为字段缺失而崩溃
