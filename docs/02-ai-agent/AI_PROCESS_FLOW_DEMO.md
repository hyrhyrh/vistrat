# AI智能处理流程可视化演示

## 🎯 功能概述

为应付领导对"与众不同"可视化展示的需求，我们在大屏系统中新增了一个炫酷的**AI智能处理流程可视化**组件。这个组件以神经网络风格展示从视频输入到告警输出的完整AI处理流程。

## 🔥 核心特色

### 1. 神经网络风格设计
- **仿生物神经元**：节点间的连接模拟神经网络
- **动态粒子流**：数据流动用动画粒子表示
- **脉冲效果**：AI核心节点有呼吸灯效果
- **渐变色彩**：科技感蓝紫色调，符合大屏审美

### 2. 流程节点展示
```
视频输入 → 智能抽帧 → 预处理 → [AI大脑] → 结果分析 → 告警判断 → 结果输出
```

每个节点都有：
- **实时指标显示**：FPS、延迟、精度、置信度
- **状态动态变化**：处理中/已完成/错误状态
- **悬浮提示框**：详细的技术参数
- **进度条显示**：当前处理进度

### 3. AI大模型突出展示
- **特殊节点设计**：比其他节点更大更显眼
- **多层脉冲环**：三层呼吸灯效果
- **紫色渐变**：区别于其他节点的特殊配色
- **性能指标**：重点展示准确率和置信度
