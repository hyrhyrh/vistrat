# 智能视频监控预警系统架构设计

## 系统概述

基于多模态视觉模型的智能视频监控预警系统，支持离线视频和实时流分析，具备图像标注、多维度提示词管理、MinIO存储等企业级功能。

## 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│                    前端 React 应用                           │
├─────────────────────────────────────────────────────────────┤
│  视频管理  │  流管理  │  提示词管理  │  预警管理  │  标注管理   │
└─────────────────────────────────────────────────────────────┘
                              │
                        WebSocket + REST API
                              │
┌─────────────────────────────────────────────────────────────┐
│                   后端 FastAPI 服务                          │
├─────────────────────────────────────────────────────────────┤
│              │              │              │              │
│   视频管理    │   流媒体     │   AI分析     │   存储服务    │
│   模块       │   处理模块    │   引擎       │   模块       │
│              │              │              │              │
└─────────────────────────────────────────────────────────────┘
                              │
                        MinIO 对象存储
                              │
┌─────────────────────────────────────────────────────────────┐
│                   外部服务集成                              │
├─────────────────────────────────────────────────────────────┤
│   多模态AI   │   视频编解码  │   实时流协议  │   数据库     │
│   模型API    │   FFmpeg     │   RTSP/WebRTC │   PostgreSQL │
└─────────────────────────────────────────────────────────────┘
```

## 功能模块设计

### 1. 离线视频管理模块
```
videos/
├── models/
│   ├── video_metadata.py      # 视频元数据模型
│   └── video_analysis.py      # 分析任务模型
├── services/
│   ├── video_manager.py       # 视频CRUD服务
│   └── analysis_scheduler.py  # 分析任务调度
└── api/
    └── videos.py              # 视频管理API端点
```

### 2. 实时视频流管理模块
```
streams/
├── models/
│   ├── stream_config.py       # 流配置模型
│   └── stream_status.py       # 流状态模型
├── services/
│   ├── stream_manager.py      # 流管理服务
│   ├── rtsp_handler.py        # RTSP协议处理
│   └── webrtc_handler.py      # WebRTC协议处理
└── api/
    └── streams.py             # 流管理API端点
```

### 3. AI提示词多维度管理模块
```
prompts/
├── models/
│   ├── prompt_template.py     # 提示词模板模型
│   ├── prompt_category.py     # 提示词分类模型

│   ├── prompt_manager.py      # 提示词管理服务
│   └── template_engine.py    # 模板渲染引擎

    └── prompts.py             # 提示词管理API端点
```

### 4. AI分析与预警模块
```
analysis/
├── models/
│   ├── analysis_task.py       # 分析任务模型
│   ├── detection_result.py    # 检测结果模型
│   └── annotation.py          # 图像标注模型
├── services/
│   ├── ai_analyzer.py         # AI分析引擎
```

### 5. MinIO存储服务模块
```
storage/
├── models/
│   ├── storage_config.py      # 存储配置模型
```

## 关键技术特性

### 多维度提示词支持
- **安全检测维度**: 安全帽、防护服、危险区域
- **行为分析维度**: 人员聚集、异常行为、工作流程
- **目标识别维度**: 车辆、设备、物品识别
- **环境监控维度**: 火灾、烟雾、污染检测

### 智能图像标注
- 自动框选检测目标
- 置信度标记
- 多语言标注支持
- 可视化检测结果

### 分析任务调度
- 异步任务队列
- 优先级管理
- 任务状态跟踪
- 资源限制控制

## 数据流设计

1. **视频输入** → MinIO存储 → 任务队列
2. **AI分析** → 结果存储 → 实时推送
3. **异常检测** → 图像标注 → 告警生成
4. **历史查询** → 数据聚合 → 可视化展示
