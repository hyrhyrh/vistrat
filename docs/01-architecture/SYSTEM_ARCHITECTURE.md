# 🏗️ AI智能视频监控预警系统 - 企业级架构设计

## 📋 架构总览

本系统采用现代化分层架构设计，从前端到后端共分为6个核心层级，每层职责明确、技术栈清晰。

![系统架构图](./architecture_diagram.svg)

## 🏛️ 分层架构详解

### 1. 🌐 前端UI层
**技术栈**: React 18 + TypeScript 5.0 + Ant Design 5.0 + Vite 4.0 + WebSocket

| 组件 | 作用 | 技术实现 |
|------|------|----------|
| React 18 | 前端框架 | 并发特性、Hooks、函数式组件 |
| TypeScript 5.0 | 类型检查 | 静态类型安全、IDE智能提示 |
| Ant Design 5.0 | UI组件库 | 企业级组件、主题定制 |
| Vite 4.0 | 构建工具 | 极速热更新、ES模块支持 |
| WebSocket | 实时通信 | 告警推送、视频流传输 |

**核心特性**:
- ✅ 响应式设计，支持多端适配
- ✅ 组件化开发，代码复用率高
- ✅ 类型安全，减少运行时错误
- ✅ 实时数据更新，用户体验流畅

---

### 2. 📱 展示层
**核心页面**: 视频监控 + 告警管理 + 分析查询 + 提示词管理 + 系统监控

| 页面模块 | 主要功能 | 关键技术 |
|----------|----------|----------|
| 视频监控界面 | 实时画面展示、多路视频流 | MJPEG播放器、WebSocket |
| 告警管理中心 | 异常事件处理、告警历史 | 实时推送、分页查询 |
| 分析结果查询 | 历史数据检索、统计分析 | Elasticsearch、数据可视化 |
| 提示词管理 | AI模板配置、场景定制 | 动态表单、模板引擎 |
| 系统监控 | 性能指标、服务状态 | 实时图表、健康检查 |

**设计原则**:
- 🎯 用户中心设计，界面直观易用
- 🔄 数据驱动，实时反馈系统状态
- 📊 可视化展示，数据洞察清晰
- 🎨 统一设计语言，品牌一致性

---

### 3. ⚙️ 业务层
**核心服务**: FastAPI + 业务逻辑处理 + API网关

| 业务模块 | 核心功能 | 技术实现 |
|----------|----------|----------|
| 视频管理 | 文件上传处理、格式转换 | FastAPI + aiofiles |
| 流媒体服务 | RTSP/MJPEG协议处理 | OpenCV + 流媒体协议 |
| AI分析引擎 | 智能检测、模型调用 | 异步任务队列、AI API集成 |
| 告警服务 | 实时推送、规则引擎 | WebSocket + 事件驱动 |
| 用户认证 | 权限管理、JWT令牌 | bcrypt + JWT + 权限控制 |
| API网关 | 路由分发、中间件 | FastAPI + CORS + 限流 |

**架构优势**:
- 🚀 异步处理，高并发支持
- 🔐 安全认证，权限精确控制  
- 📡 RESTful设计，接口标准化
- 🛡️ 错误处理，系统稳定可靠

---

### 4. 🧠 服务层
**核心引擎**: 视频处理 + AI分析 + 存储管理 + 监控服务

| 服务组件 | 主要职责 | 技术方案 |
|----------|----------|----------|
| 视频处理器 | OpenCV视频解析、帧提取 | OpenCV 4.8+ + FFmpeg |
| AI模型选择器 | 智能调度、性能优化 | 多维度评分算法 |
| 存储服务 | 文件管理、对象存储 | MinIO + 本地文件系统 |
| 缓存服务 | 数据缓存、会话管理 | Redis + 内存优化 |
| 消息队列 | 异步任务、解耦处理 | 基于Redis的任务队列 |
| 健康检查 | 服务监控、故障恢复 | 心跳检测 + 自动重启 |

**设计亮点**:
- 🎯 智能调度，资源利用最优化
- 🔄 异步解耦，系统响应更快
- 💾 分层存储，数据管理高效
- 🔍 全链路监控，问题快速定位

---

### 5. 💾 数据层
**存储架构**: PostgreSQL + Elasticsearch + Redis + MinIO + 本地文件

| 存储类型 | 主要用途 | 技术选型 | 数据特点 |
|----------|----------|----------|----------|
| PostgreSQL 16 | 主数据库 | 关系型数据库 | 用户信息、视频元数据、系统配置 |
| Elasticsearch 8.11 | 搜索引擎 | 分布式搜索 | 分析结果、告警记录、全文检索 |
| Redis 7 | 缓存数据库 | 内存数据库 | 会话信息、配置缓存、实时数据 |
| MinIO | 对象存储 | 云原生存储 | 视频文件、图片、大文件存储 |
| 本地文件系统 | 临时存储 | 文件系统 | 日志文件、临时缓存、配置文件 |

**数据流向**:
```
用户操作 → 业务逻辑 → 数据持久化
   ↓           ↓           ↓
实时缓存 ← 搜索索引 ← 主数据库
   ↓           ↓           ↓  
前端展示 ← 分析结果 ← 对象存储
```

## 🔗 关键技术集成

### AI模型集成架构
```
前端请求 → FastAPI网关 → AI模型选择器 → 多模态分析
    ↓           ↓            ↓            ↓
结果展示 ← 数据存储 ← 结果解析 ← AI模型API
```

**支持的AI模型**:
- **通义千问VL-Max**: 视觉理解、图像分析
- **Moonshot-v1**: 文本分析、上下文理解  
- **向量数据库**: RAG知识检索增强

### 流媒体处理架构
```
视频源 → OpenCV处理 → MJPEG编码 → HTTP流传输 → 前端播放
  ↓         ↓          ↓          ↓          ↓
RTSP流 → 帧提取分析 → AI检测 → 告警推送 → 实时展示
```

**流媒体特性**:
- 🎥 支持RTSP、本地视频多种输入
- 🔄 15FPS低延迟实时传输
- 🧠 智能帧抽样，性能优化
- 📡 基于HTTP的MJPEG流协议
