### 第二段：系统架构展示 (0:30 - 1:30)

**画面内容**: 系统架构图 → 技术栈介绍  
**解说词**:

> 我们的系统采用现代化的**企业级分层架构**设计。
> 
> **前端层**使用React 18和TypeScript构建现代化界面，**业务层**基于FastAPI提供高性能异步API服务，**AI服务层**集成了通义千问VL-Max视觉模型和Moonshot文本模型，**数据层**采用PostgreSQL+Elasticsearch的混合存储架构。
> 
> 核心创新点是我们的**智能AI模型选择器**，能够根据检测任务特征和历史性能数据，动态选择最优的AI模型，大大提升了检测准确率和系统效率。
> 
> 流媒体方面，我们自研了基于OpenCV的**企业级MJPEG流媒体服务**，支持15FPS低延迟实时传输，可同时处理10路视频流。

**操作演示**:

## 🎨 演示技巧与要点

### 录屏技术要求

1. **分辨率设置**: 1920x1080 (Full HD)
2. **帧率设置**: 30FPS，确保流畅播放
3. **音频质量**: 清晰的人声讲解，无背景噪音
4. **界面展示**: 确保文字清晰可读，操作明显易见

### 演示节奏控制

- **语速控制**: 中等语速，重点内容略慢
- **停顿技巧**: 重要功能演示后给予2-3秒展示时间
- **切换节奏**: 界面切换要流畅，避免突兀跳转
- **互动感**: 适当使用"我们可以看到"、"接下来"等过渡语

### 关键演示点

1. **突出AI能力**: 重点展示多模态分析的智能化程度
2. **强调实时性**: 体现告警推送的毫秒级响应
3. **展现专业性**: 通过架构图和技术栈体现系统的企业级特质
4. **证明价值**: 用具体数据说明效率提升和成本节约
